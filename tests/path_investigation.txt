Deterministic confirmed witnesses
--------------------------------
Create a regular file named file, cwd its directory:
  expand("file") == bytes "file/"; metadata changes success -> ENOTDIR.
  expand("file-link") for symlink to file also adds / and changes success -> ENOTDIR.
  expand("./file/") == bytes "./file"; metadata changes ENOTDIR -> success.
With HOME=<fixture>, expand("~/file/") and expand("~/file/.") both become
<fixture>/file, changing ENOTDIR -> success. Absolute non-tilde paths share this
behavior. Nested file and directory-symlink/parent variants reproduce it.
With HOME=<fixture>/file, expand("~") adds / and changes success -> ENOTDIR.
Bare relative file/. becomes file/ and retains ENOTDIR: context matters.

Root cause and minimal repair recommendation
------------------------------------------
Path::components trims suffix separators/dots, while unconditional push of an
empty remainder adds a slash to a single component. PathBuf equality conceals
these changes. Parse original first byte component, preserve non-expanding paths,
and append original suffix bytes directly to resolved home, not PathBuf::push of
an absolute /suffix. Parent owns focused fix and production regression tests.

Sensitivity and follow-up coverage
----------------------------------
Known filesystem witnesses demonstrate semantic-oracle sensitivity in both
slash insertion and removal directions. An explicit all-components-tilde mutant
is rejected by the independent byte grammar; a spurious slash is distinguished
by byte comparison while demonstrating Path equality's blind spot. No production
mutation is left behind. After initial pass, added unrestricted byte tails up to
2047 bytes, relative filesystem witnesses, and interior-dot/parent variants.

HOME mutation is isolated in a dedicated child test binary. Empty/unset HOME
fallback is checked using an independent getpwuid_r provider query with ERANGE
retry; fallback was available on the host. Every mutation is immediately observed
with both bare ~ and a dot/parent/non-UTF8 suffix, so random histories cannot omit
warm -> mutate -> query. APIs: OsStr, OsString, Path, PathBuf, str and String.

Blind spots / non-claims
-----------------------
Named-user/account lookup semantics are owned by another worker. No missing-UID
fallback environment was available; no HOME-absence error branch claim. Windows,
other Unix filesystems, network double-slash semantics, permission-sensitive
traversal, concurrent external environment writers, and arbitrary mount behavior
were not tested. The component quotient intentionally removes dot/separator
lexical noise and is NOT a filesystem oracle. Symlinks/dots/parents are checked
separately on real fixtures. HOME cannot contain NUL by OS environment contract.
